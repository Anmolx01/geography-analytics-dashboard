# Geography Analytics Dashboard

## Overview

An interactive Power BI dashboard developed during my Data Analytics internship at DataMelon Labs to analyze geographical business performance.

The dashboard evaluates regional, state, city, store-tier, store-format, category, brand, SKU, and shopping behaviour.

## Key Features

- Regional sales analysis
- State-level performance
- City-level sales analysis
- Customer and transaction analysis
- Store-tier performance
- Store-format analysis
- Monthly regional trends
- Top category analysis
- Brand performance
- Category opportunity matrix
- Top SKU analysis
- Average Selling Price analysis
- City shopping behaviour

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization
- Business Intelligence

## Dashboard Pages

### Regional Overview
Analyzes sales, transactions, ATV, quantity, customers, states, cities, tiers and store formats.

### City Shopping Behaviour
Analyzes category preferences, brands, SKUs, category opportunities and shopping trends for selected cities.
